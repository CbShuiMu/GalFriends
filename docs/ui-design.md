# GalGear UI 对照与 GalFriends 约定

此文记录实际源码中的最终规则。后续修改界面先查此文，再核对原实现；不能只参考早期的 `styles.css`，或重新凭印象设计工具栏。

## 原实现的阅读入口

参考项目：相邻工作区 `../GalGear`。

- `web/index.html`：样式顺序为 theme → styles → detail → library → appearance → home。后加载的 appearance 决定按钮最终外观。
- `web/appearance.css`：主题表面、按钮、胶囊圆角、选择状态和工具栏覆盖规则。
- `web/library.css`：72px 导航、工具栏、添加菜单、卡片和收藏夹布局。
- `crates/ui/src/library/view.rs`：`toolbar` 与 `collection_toolbar` 是不同的视图。根收藏夹、子收藏夹和多选模式分别生成不同操作。
- `crates/ui/src/library/dialogs.rs`、`actions.rs`：收藏夹编辑、添加已有条目和删除确认流程。
- `crates/ui/src/choices.rs`、`web/bridge.js`：排序的自定义下拉、添加菜单展开及焦点处理。
- `web/home.css`、`home.js`、`home-backdrop.js`：首页布局、选中封面和立绘切换；`detail.css` 维护详情专属规则。

## 视觉规则

| 元素 | 约定 |
| --- | --- |
| 普通操作按钮 | `border-radius: 999px`，纯图标按钮为圆形；统一半透明主题表面，无浮起位移。 |
| 例外 | 导航项保留 8px 圆角；卡片、文件夹封面、相册图片保持内容卡片形状。排序下拉触发器保留原版 7px，菜单行 6px。 |
| 导航 | 72px，图标 22px，导航按钮 48px；角色库使用 Person。无搜索入口。 |
| 工具栏 | 最小高度 66px，内边距 12px 13px，间距 8px，圆角 13px；多选与普通状态共用主题表面。图标按钮 34px。 |
| 颜色 | 使用 `--canvas`、`--toolbar-surface`、`--button-bg`、`--button-hover-bg` 等原版主题变量；不单独给一批按钮添加方形或高饱和覆盖。 |
| 一般交互 | 颜色过渡 160ms。添加菜单 320ms、`cubic-bezier(.22,1,.36,1)`；选项淡入 180ms。减少动态效果时停用。 |
| 页面文字 | 主页面不增加左上角标题和宣传语。人物名、介绍、表单标签、弹窗标题和收藏夹路径属于必要内容。 |
| 确认弹窗 | 操作区统一使用右下角 `dialog-actions`；角色、收藏夹删除及标签隐藏从左到右为“确认”“取消”，共用 `confirmation_actions`。默认聚焦取消，Tab 保留视觉顺序；提交中禁用按钮，成功才关闭，失败保留确认与选择。 |

## 两种工具栏

角色库：左侧只显示角色数量；右侧本地别名搜索、带“标签筛选”文字的筛选按钮、多选、添加菜单、刷新、升降序、自定义排序下拉。添加菜单向左展开，唯一选项为“导入角色”：进入 Bangumi / 鲲 Gal / VNDB 在线搜索与导入流程；批评空间仍只查关联作品。没有本地 JSON 文件导入。

收藏夹根目录：左侧新建收藏夹，右侧多选。进入收藏夹后显示路径、编辑；允许的层级提供新建子收藏夹，叶子收藏夹右侧提供添加已有角色。多选时左侧为计数、全选、清空，右侧为删除所选收藏夹、移出所选角色、完成。此栏没有角色库的搜索、排序、刷新或在线导入按钮。保留“已收藏”虚拟文件夹访问角色的星标收藏。

收藏夹沿用两级层次。旧平铺收藏全部作为根目录项，缺省父级映射为空；改名保留角色与子收藏夹关系，删除收藏夹只移除收藏关系。失败保留输入与选择，成功响应后才发布更新。

角色库多选的“加入收藏夹”沿用 GalGear 的 520px 弹窗。顶部显示标题和关闭图标，正文显示所选数量、自动聚焦的搜索框和文件夹列表，底部右侧提供关闭按钮。搜索按完整路径匹配，可接收角色的收藏夹显示为“父级 / 子级”。选中一行即提交，成功关闭，失败保留搜索词和选择。新建收藏夹在收藏夹页面完成。

## 用户明确要求的卡片差异

角色卡片宽 200px、比例 3:4，与详情页同步当前选中的立绘，优先显示该图的超分结果，保留上半身裁剪。悬停与键盘聚焦复用 GalGear 的 160ms 淡入和 7px 位移，操作延后 80ms；方案 D 左下横排姓名浮签，右下竖排红色心形收藏和删除，不显示标签或通关按钮。浮签距左边 12px、底边 16px，胶囊圆角、内边距 5px 12px、半透明浅色背景 #fffafde8，沿用方案 D 草图的细边框与轻阴影。名字在明暗主题、悬停和键盘聚焦时均为黑色，无文字阴影；长名字单行省略，悬停提示保留全名，宽度为右下按钮预留空间。只有右下操作使用从右边缘向内渐隐的椭圆渐变，明确限定椭圆半径保证左侧和内侧边缘完全透明；其余区域透明，不模糊立绘。右下操作栏宽为名字行高加 24px（默认约 51px）。名字字体为 Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI / Microsoft YaHei，字号为 ui-font × 1.06、字重 600、行高 1.6。首页独立生成静态卡片，没有悬停层；心形收藏使用同一共享组件。

角色库和收藏夹的角色卡片底色、边框分别使用 `--surface`、`--surface-line`，随粉色、白粉、白色及各自明暗模式切换；透明立绘和无图占位共用该表面，不使用仅区分明暗的固定粉色变量。首页卡片继续使用随主题变化的 `--canvas`。

## 实现边界

`shell.css` 统一主题控件外观，随后加载 `appearance-palettes.css` 的可选配色、`preferences.css` / `connections.css` 的设置控件，以及 `character-tags.css` 的详情标签组件；`library.css`、`collections.css` 分别管理两种布局。`toolbar.js` 只处理展开、定位和焦点，排序值、收藏夹与成员草稿仍由 Rust UI 管理。新增静态文件必须进入前端构建复制清单。


## 首页切换

首次加载在内容区中央显示主题色进度环、“正在加载角色库…”及本地资料读取说明。初始化期间仅保留这一处状态反馈，侧栏操作暂不可用。失败后原位显示错误标题、可展开的完整错误详情和胶囊重试按钮，并将焦点移到重试按钮。重试期间恢复加载状态，成功后焦点移到主内容区。加载动画遵循减少动态效果偏好，状态文案包含中文、日文和英文。

`home.css`、`home.js` 和 `home-backdrop.js` 移植 GalGear 原始首页的选中卡片伸缩、左侧对齐和定向滑动淡入。卡片高度采用原版响应式数值，伸缩为 320ms、`cubic-bezier(.2,.7,.2,1)`；选中环与卡片间隔 4px。滚动跟随变化中的卡片位置，末项也能对齐左侧。首页展示全部角色，点击、左右键、Home/End、滚轮和手柄聚焦均通过 Rust 的 `select` 更新选择。

背景过渡采用 440ms、`cubic-bezier(.22,.75,.2,1)`，位移为首页宽度的 4.5%、最多 56px，前后切换方向相反。沿用串行解码与双层动画：保留当前淡入直到完成，快速切换仅接续最后一次选择；图片缺失或加载失败时淡出旧图，离开首页后不接收迟到图层。减少动态效果时立即对齐并取消动画。

`home-render.js` 只在连续首页渲染时保留容器、卡片和背景宿主，其他内容继续使用既有替换流程，避免收藏响应、弹窗或主题变化打断首页动画。首页卡片同步详情页选中的立绘与超分结果，使用 3:4 上半身裁剪；背景显示用户选中的透明全身立绘，不使用游戏封面的模糊铺底，也没有卡片悬停层。

## 设置页

对照 GalGear 的 `crates/ui/src/preferences.rs`、`web/styles.css` 与 `web/appearance.css`：左侧 210px 分类栏，间距 36px；1000px 以下改为 170px / 24px，760px 以下改为顶部分行导航。右侧设置卡片 26px 内边距、14px 圆角，选项行用细分隔线。分类按钮无边框、9px 圆角，背景使用最终 button 主题变量；选中项字重 650，文字同色下划线偏移 6px，不使用粉色伪元素线。选项使用胶囊分段控件，滑块采用 280ms 过渡。

保留数据源、AI、显示、系统、路径与工具、关于分类。显示页提供三种语言、粉色/白粉/白色配色、明暗模式及 14/16/18px 字号；数据源页提供默认角色搜索源和标签源。代理沿用原有保存入口，路径页从桌面运行时读取独立角色库、应用缓存目录及 waifu2x 可执行文件检测结果。没有迁入原版的游戏启动、云盘、补丁及下载设置。

配色、字号和默认来源使用带缺省值的持久字段，保存成功后更新界面；失败保留旧值和输入。分段按钮支持左右键、Home/End，保存过程中保留焦点；分区切换和滑块动画遵循减少动态效果偏好。卡片保持 200px / 3:4，不提供覆盖用户指定尺寸或悬停方式的设置。


## 主题与连接页面

主题重新复制 GalGear 的 `theme.css`、`appearance.css` 中完整配色和表面规则，包含三套配色的明暗版本、控件表面、导航、卡片阴影。已移除全局纯白覆盖。GalGear 自身浅色 main-panel 的白色规则保留，侧栏、工具栏、设置卡片和首页使用其原配色。

数据源页按 GalGear `preferences::account/source_card` 排列：顶部同行的默认搜索源与标签来源、鲲 Gal / Bangumi / VNDB / 批评空间卡片，标题与右侧状态、Token 输入、底部图标操作。保留 Bangumi 与鲲 Gal 浏览器登录与取消；VNDB 提供 Token 保存验证/清除，批评空间仅有网站入口。鲲 Gal 不迁入补丁密钥字段。标签来源在默认搜索源右侧，仅允许鲲 Gal / VNDB；极窄窗口或大幅缩放时自动换行。

AI 页对照 `crates/ui/src/ai.rs` 与 `web/appearance.css`，保留当前服务的带 Logo 分段选择、四张配置卡片、Token、模型刷新、可搜索模型选择、保存和清除；宽屏两列、1100px 以下单列。窄窗分段控件允许横向滚动，选中项保持可见。模型搜索和选择支持键盘，弹层关闭后恢复焦点；状态区明确区分未配置、处理中、已保存、已清除和错误。不迁入原页顶部标题/说明段。


## 角色详情

详情页顶部只保留返回按钮，不显示关联来源和收藏按钮；立绘相册后不再显示资料来源、加入收藏夹和删除区域。完整来源快照继续保存在角色资料中，收藏、收藏夹和删除仍通过角色库与收藏夹已有入口操作。

全部别名沿用 GalGear 详情信息栏布局：每组上方为加粗的类型标签，下方为名字，横向五列，让第五项别名（如 `zh-Hans`）位于首行最右侧，不使用表格分隔线；1100px 以下换为两列。文字颜色复用主题变量，字号随界面设置缩放，长文本换行，所有非空别名均保留显示。

## 详情标签

`character-tags.css` 直接复用 GalGear 的胶囊、两侧展开阴影、编辑/移除按钮的 scaleX 动画和输入框样式；`detail-tag-reorder.js` / `press-gesture.js` 复用长按拾起、让位和落下动画，支持 Alt + 左右键及减少动态效果。Rust 负责排序保存与失败反馈。标签可修改本地显示名、隐藏、恢复来源和点击筛选；来源字段、分组及剧透属性不变。

标签列表左边缘与“角色标签”标题对齐，换行后保持同一左边缘；仅在右侧为悬停操作保留 28px 空间，触屏布局不保留侧边缩进。

## 主题过渡、字号与窗口

`theme-transition.js` 在主题保存成功后的渲染中复用 GalGear 的 View Transition：从点击位置（键盘操作取控件中心）以 520ms 圆形扩散。切换过程中和保存成功后均不弹提示，失败保留旧主题并显示错误；旧 WebView 使用 480ms 淡出回退，减少动态效果时直接切换。渲染代次阻止迟到的截图回调覆盖新状态。

明暗模式和配色使用 `set_appearance` 轻量命令，只原子更新库索引中的设置并返回两个配色字段，不复制、比较或回传完整角色图片。Rust 只生成主题按钮与配色分段控件的 HTML 片段；DOM 原位更新根主题属性及这些控件，保留页面、立绘、滚动与输入节点。保存中如果导航或后台响应触发整页重绘，完成后使用整页渲染恢复正确的控件禁用状态。失败仍保留原主题并显示错误，不提前宣告成功。

基础字号默认 16px、行高 1.55。工具栏与搜索为 ui-font × .78，排序选项为 ui-font × .9286，计数为 ui-font × 1.12；均随 14/16/18px 设置缩放。排序弹层从触发器左边缘展开，至少与其等宽，保持 6px 间距，临近窗口边缘时调整位置。导入角色使用 Person 图标。

原生窗口沿用 GalGear 的 1240×820 默认尺寸、1122×640 最小尺寸；允许缩放与最大化，未设置最大尺寸上限。角色卡片仍固定 200px，不迁入 GalGear 的可变游戏封面尺寸。

## 在线搜索弹窗

搜索源使用整组居中的胶囊分段按钮，每项显示对应网站 Logo 和名称；Logo 与设置页共用 widgets 中的资源映射，复用设置页分段控件的选中滑块、左右键与 Home/End 导航；切换来源保留关键词并清空旧结果，请求中禁用切换。搜索按钮只显示放大镜，保留本地化的悬停提示和可访问名称；打开弹窗先聚焦输入框。弹窗宽 640px，结果立绘卡面为 84×112px（3:4），行内上下各留 16px；标题和查询控件固定，结果区单独滚动，滚动条为随明暗配色变化的细条和透明轨道。

搜索候选通过可选 `portrait` 字段传递 Bangumi 搜索响应中的角色图片（优先 medium，依次回退 large/small/grid），直接展示上部裁剪的缩略图，不额外逐项拉取相册。沿用 Bangumi 图片域名校验；无图和加载失败时显示人物占位图标，仍可导入。鲲 Gal、VNDB 不按同名猜测 Bangumi 图片，批评空间保留作品图标。缩略图不替代导入时的完整相册及原始资料。

候选姓名下显示来源提供的可选 `romanized_name`：Bangumi 取别名中的“罗马字”，鲲 Gal 取 `latin`，VNDB 取 `name`。字段缺失、为空或与主名重复时不生成该行，不从假名自动音译，也不把未分类别名猜作罗马字；旧候选缺少字段时默认为空。来源及 ID 保留在下方。

## 导入进度提示

在线导入的右下角消息框只显示当前阶段：正在导入角色 → 正在下载立绘 → 正在去除背景 → 正在超分立绘 → 正在保存角色。图片逐张处理，多张时附当前张数/总数；无立绘或复用已有立绘时跳过图片阶段。阶段由实际后台步骤驱动，成功与失败仍由最终命令响应确认。

消息框保留固定宽度和进度环，只切换单行文字：旧文字向上移动并淡出，新文字从下方移入并淡入，时长 300ms。连续快速通知合并到最新阶段；导航和后台刷新保留消息节点，完成后清理动画层，迟到通知不再显示。遵循减少动态效果偏好，直接替换文字；长文本单行省略并保留完整悬停提示，支持三种语言和字号缩放。

所有右下角消息弹窗首次出现时从下方 12px 滑入并淡入，时长 280ms；流程结束或自动关闭倒计时到期时用 200ms 平滑淡出。重绘保留同一消息节点，不重复入场；退场使用不接收交互、不参与播报的临时视觉层，动画结束即清理，期间刷新页面也不会打断淡出。减少动态效果时直接显示与移除，运行中开启该设置也会立即完成动画。

## 立绘选择保存

详情点选立绘即时预览已有图片，后台通过轻量命令保存序号，换图期间不显示通用“正在处理”提示。连续点选合并为每个角色的最后一次选择，迟到响应不会覆盖新的预览。保存失败显示错误并恢复已保存选择；首页、角色库和收藏夹共用预览及已确认选择。

详情标签末尾沿用 GalGear 的横排胶囊图标按钮，＋添加本地标签，数据库图标打开仅含鲲 Gal / VNDB 的角色搜索，用于替换当前角色的标签来源。两个图标按钮的宽高与两个汉字的标签一致，默认字号下为 48×28px，并随字号和缩放同步变化。常态背景和文字使用 GalGear 的通用按钮主题，悬停时使用对应的高亮色，键盘焦点保留轮廓。保存成功后关闭弹窗并留在详情，失败保留选择。自动抓取的加载、错误与重试位于标签区，网络等待期间本地功能可用。设置中的标签来源增加“跟随语言”，中文选择鲲 Gal，英文和日文选择 VNDB。

标签输入框与 GalGear 一致，使用 `size="1"` 和 CSS 的文字测量伪元素，空输入宽度由原版 `2em` 下限决定，输入后随文字伸缩，最长限制为 `min(50vw, 32em)`。输入法组合期间同步测量文字，业务草稿仍由 Rust 保存。

## 声音训练工作台

72px 侧栏增加 `mic` 图标，使用与其他导航一致的悬停提示与可访问名称。工作台不设页面标题，模型状态、游戏素材和角色训练使用既有设置卡片。素材中的说话人与角色库角色分别选择，训练语言固定日语。

声音训练的引擎、角色、说话人、语言，以及情绪参考的角色选择，统一复用角色库排序的 `choice-control` 样式：7px 圆角触发器、6px 圆角选项、主题浮层与选中勾。`web/choices.js` 读取 Rust 渲染的原生选项增强展示，通过既有 change 桥接提交选择，不复制业务状态。触发器中的长名称单行省略并保留完整悬停提示，菜单名称可换行；列表限制在窗口内，空间不足时向上展开并滚动。

下拉框支持鼠标、上下方向键、Home/End、Enter/空格、首字母查找、Escape 和 Tab；打开时定位当前选项，选择或 Escape 后回到触发器，点击外部关闭。页面重绘保留展开列表、焦点与滚动位置；任务期间及无可选角色时禁用相应控件。手柄在展开的列表内导航，B 关闭并恢复焦点，右摇杆滚动当前列表。标签与可访问名称沿用原有三语文案。

顶部工具栏的下载图标打开基础权重选项，逐项启动下载。取消按钮位于同一工具栏。长任务的阶段和结果复用右下角消息弹窗，高频进度只更新文字。离开工作台后仍显示阶段，返回后可取消任务。取消携带任务 ID，迟到的取消请求不能终止后续任务。

## 桌面角色窗口

角色资料页右侧麦克风按钮打开当前角色的透明桌面窗口。窗口保留全身立绘，采用当前选中图片及其超分结果；顶部紧凑胶囊提供姓名拖动区、置顶、资料/模型和关闭。中段半透明对话框显示中文和日语，输入框支持 Enter 发送、Shift+Enter 换行和 IME 组合保护。界面实时跟随主窗口已保存的语言、主题、配色和字号，窗口可缩放；同步时保留对话、草稿、焦点、滚动位置与运行中的任务，IME 组合结束后再刷新。

对话记录、输入框和展开资料共用透明轨道的细滚动条，移除上下箭头；8px 操作区域内显示 4px 圆角滑块，悬停和拖动时加深，颜色跟随明暗主题。滚动槽预留固定空间，消息文字与滑块保持间距，内容溢出时才显示滑块；支持滚轮、触控板和拖动，高对比度模式使用系统文字色。

生成过程中保留上一轮文字，明确区分 AI 等待与日语合成；取消和失败后恢复输入，日语重播不重复请求 AI。设置区用两个下拉框选择引擎和已训练模型，通过后端校验并保存后更新当前绑定。两个窗口的输入、历史、取消状态和音频各自独立。

## 情绪参考页

侧栏使用提供的 `voice_chat` 图标。页面顶部仅显示悬浮角色选择、刷新和 AI 推荐图标按钮，保留可访问名称与悬停提示。五种情绪使用自适应卡片，每条显示日语原文、时长、试听和选用，已确认参考单独保留。原生音频控件支持键盘，切换页面停止播放；请求进度局部刷新，失败保留原选择。所有文案覆盖中日英。

顶部使用间距 16px 的等宽双列：悬浮角色选择卡片占左半栏，试听后的音频播放控件位于右半栏并垂直居中；未试听时保留右侧空位。说明和情绪卡片继续占满内容宽度。窗口不超过 1000px 时改为单列，播放器移至选择卡片下方，避免压缩控件。

筛选进度、等待取消、成功与错误统一进入右下角消息弹窗。进度显示当前批次，和导入共用 300ms 向上淡出、下方进入的文字动画；页面切换保留任务提示，取消入口位于页面工具栏，取消期间禁用按钮并忽略后续批次进度。消息弹窗不显示关闭或取消按钮；任务结束开始淡出进度提示，保存、推荐完成和取消结果显示 3 秒后自动淡出，错误显示 6 秒后自动淡出。倒计时跨重绘保持，到期清理 Rust 状态，迟到计时器不能关闭新消息。多任务消息在右下角纵向排列，不覆盖彼此；通知更新保留音频播放和当前焦点。

## 作品与游戏库联动

路径与工具顶部卡片首行提供 GalGear 游戏库路径输入框和保存图标，接受库文件或数据目录，空值关闭联动。角色相册下仅展示鲲 Gal 出演作品，左侧 48×64 封面，右侧最多两行标题。标题打开鲲 Gal 作品页。安装通过来源 ID 或封面内容摘要自动关联，在声音训练页选择。

声音训练页把角色选择放在素材卡片顶部，下方提供关联游戏选择、刷新与路径设置入口。用户选择后填入游戏目录，再选择独立输出目录。AI 解包按钮复用 GalGear 宿主与 GalExtract，并使用本应用配置的 OpenAI 或 DeepSeek，真实进度、完成和错误继续使用共用右下角通知。解包完成后核对实际脚本说话人并启动已有训练流程。
