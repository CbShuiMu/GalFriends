# 桌面角色陪伴

角色资料页角色名右侧的麦克风按钮，以及角色库与收藏夹卡片悬停时收藏按钮上方的蓝色麦克风按钮，均打开对应角色的独立透明窗口。窗口采用当前选中立绘（优先超分结果），支持拖动、缩放、置顶切换和关闭。对话框位于立绘中段；Enter 发送，Shift+Enter 换行，输入法选字的 Enter 不会误发。

先在设置 → AI 保存服务凭据、选择模型和当前服务。支持既有 OpenAI、DeepSeek、Qwen、Kimi 的兼容聊天端点。每次请求发送姓名、介绍、角色专属人格资料（如有）及当前窗口最近六轮对话。立绘、训练文件、完整 API 快照、原剧本和本地路径留在本机。回复要求 JSON 中包含 `chinese`、`japanese`，验证通过后展示双语。日语交给选中的 IndexTTS 2.5、GPT-SoVITS v5Turbo 或 GPT-SoVITS v2Pro。

刹那、悠果与鬼月零按角色库 ID 装载各自的 [Nightmare 人格资料](nightmare-story-and-personas.md)。资料来自确认出场的作品与《终末》之后的主线时间点，原人物介绍独立保留。切换角色会选用该角色自己的经历、关系和语气。

打开悬浮角色设置，选定语音引擎后，从下方选取同一角色和引擎的已训练模型，选择后立即校验并保存绑定。列表可刷新。角色目录下的已完成模型和已有绑定所在目录自动纳入浏览范围，其他旧训练目录可在声音训练页登记。各引擎分别保存路径。旧版字符串绑定自动读作 IndexTTS，下一次原子保存时迁移为 `{selected, models}`，保留原路径。应用新模型会清除旧模型的重播音频。

GPT-SoVITS 目录须包含 `model.json`、`gpt.ckpt`、`sovits.pth`、`reference.wav`、`reference.txt`。v5Turbo 推理加载底模并合并角色 LoRA，采用 4 步生成。v2Pro 加载角色生成器权重和官方说话人编码器。两种模型都使用匹配的参考台词和 `all_ja`，校验角色身份、模型格式、底模及产物 SHA-256。所有引擎共用 GPU 任务互斥和取消机制。

IndexTTS 目录须包含 `model.json`、`adapter.pth` 和 `reference.wav`。各引擎绑定均按角色 ID 校验，要求 `language: ja`、`verification_only: false`；错误角色、中文模型、验证样本和越界文件名会被拒绝。绑定原子保存至可执行文件旁的 `characters/<角色目录>/voice-model.json`，不复制或改写模型；删除角色时绑定记录随专属目录清理，不追踪或删除外部训练目录。后续重新打开可以直接聊天。

## 实现边界

- `core/companion` 定义资料、双语对白及模型绑定校验；`connections/chat` 复用凭据授权头、代理和有限响应读取。生成请求不自动重试，超时 90 秒；取消后立即丢弃结果，已经提交的 HTTP 请求可能仍由服务端处理。
- `src-tauri/companion` 创建窗口并维护各自最近六轮历史。窗口身份由后端决定；不能通过前端参数读取另一个角色的会话。关闭窗口取消任务并释放历史，重新打开是新会话。主应用退出会结束全部角色窗口及工作进程。
- `ui/companion` 是独立 WASM 状态机，管理草稿、等待、失败、取消和迟到响应。`web/companion.js` 只处理 DOM、输入法、音频和原生窗口操作；复用键盘/手柄焦点导航。
- `voice/python/speech.py` 使用官方 2.5 推理实现，在内存中加载该角色 LoRA，并核对基础 GPT 的 SHA-256。固定 `lang=ja`，不加载 Qwen 文本情绪模型。参考音频编码完成后，通过上游进度回调将语义编码器移回 CPU，为 8 GB 显卡释放解码显存；采用单束解码。每次推理进程单独加载模型，包含模型加载等待，当前没有常驻显存服务。合成进程最长运行 10 分钟，超时清理进程树。
- 训练和所有角色的语音合成共用一个 GPU 租约；占用时显示忙碌，已有文字保留，可点击播放重试。取消会终止对应合成进程树。音频先校验非空、有限、非静音及长度，再以 WAV data URL 返回；播放结束可重播，生成文件读出后删除。缓存目录是应用专属缓存，原始游戏和训练模型只读。

主界面保存语言、明暗模式、配色或字号后，所有已打开的角色面板同步更新，无需重新打开。桌面端发送仅含显示设置的 `display-preferences-changed` 事件，悬浮窗口先订阅再加载资料；初始资料的迟到响应不能覆盖新设置。同步不占用聊天、模型绑定或合成请求，保留输入草稿、焦点和滚动位置；输入法组合结束后再刷新面板。

当前不持久化聊天记录，不支持更换正在聊天窗口中的人物身份。更新主库姓名、介绍或立绘后，重新打开角色窗口以加载最新资料。尚未配置独立发行包中的 Python/CUDA 运行时。

接口依据：[Tauri 窗口定制](https://v2.tauri.app/learn/window-customization/)、[DeepSeek 多轮对话](https://api-docs.deepseek.com/guides/multi_round_chat/)、[DeepSeek JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。

## 情绪参考音频

导航的 `voice_chat` 图标打开情绪参考页，默认选择最近聚焦的悬浮角色；多个悬浮角色可通过下拉框切换。首次推荐使用该角色已绑定模型的训练素材，须保留素材目录内的 `dataset.json` 和 `audio/`。页面读取训练器生成的日语台词和 3–10 秒短音频，点击 AI 推荐后，将临时数字编号和台词分批发送给设置中选定的 AI 服务，每类择优推荐 5 条。文本判断无法确认真实声学表现，用户可试听后为正常、开心、悲伤、愤怒、害羞各选一条。符合条件不足 5 条时显示实际数量。

每次点击“选用”立即原子保存至角色专属目录的 `emotion-references.json`，包含素材来源目录 `source_dir`、推荐、已选台词及音频 SHA-256。各角色分别保存五类情绪的选择；关闭角色窗口、切换页面或退出应用后，再打开同一角色会自动恢复“已选用”状态，直接用于后续对话。重新推荐保留已选参考。v5Turbo、v2Pro 与 IndexTTS 共用该角色的五类选择，切换引擎或模型目录后继续从原素材来源读取同一条音频及台词；原素材目录需要保留。旧配置的 `model_dir` 自动作为素材来源读取，下次保存时写为 `source_dir`。关闭悬浮角色或删除角色发生在筛选期间时，提交会重新检查角色身份。取消在当前网络请求返回后完成，部分结果不保存。

聊天 AI 在同一次双语回复中标注情绪，取值为 `normal`、`happy`、`sad`、`angry`、`shy`。使用 v5Turbo 时，AI 只在情绪明显转折且说话会自然停顿的地方拆分日语对白，最多五段。相邻的同情绪段会合并，完整显示文本由各段原文直接拼成。v5Turbo 在同一个语音任务中加载一次权重，每段使用对应情绪的参考，合成后拼成一个 WAV 播放。v2Pro 和 IndexTTS 按整条回复的主情绪合成。

合成在本地选择对应参考和匹配台词。该类未选时使用已选正常参考，正常也未选时使用模型自带参考。旧回复缺省正常，非法情绪拒绝。音频内容变化、越界路径和损坏 WAV 会报错。用户选择只影响后续合成，已有重播仍播放原音频。
