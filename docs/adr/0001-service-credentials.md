# 连接配置与凭据隔离

状态：已采用，2026-11-14。

用户要求复刻 GalGear 数据源和 AI 设置，并明确选择复用其现有 OAuth 服务。沿用原授权协议和 PKCE，另以 GalFriends 配置路径摘要生成独立系统凭据目标，不迁移或读取原应用的登录状态。

普通角色库 JSON 仅保存当前 AI 服务标识。密钥、刷新令牌和已选模型均保存在同一 Windows Credential Manager 记录里，验证完成后一次替换，避免密钥成功而模型保存失败的部分配置。UI 只接收配置状态和模型 ID，密钥输入保存成功即清空。凭据读写与刷新通过模块事务串行化，角色库不参与该锁。

新增的 windows-sys 凭据接口、sha2 和 getrandom 仅用于 desktop feature。标准库缺少系统凭据 API 和密码学随机数能力；复用当前依赖树中的版本，无额外运行时或前端包。它们支持 Windows，WASM 不启用。依赖分别遵循其 Apache-2.0/MIT 许可。

独立连接请求 ID 保证晚到响应不会误匹配角色库操作。每个服务单独禁止重复操作，取消授权不会丢失其他页面的本地保存。网络失败保留草稿和旧凭据，不显示成功，也不回落为伪造模型列表。

验证使用临时目录名隔离的真实系统凭据记录、本地 HTTP OAuth 交换夹具与前端模拟桥接。真实服务账号登录和真实 API Key 需用户提供并自行授权，本轮不会读取其他应用凭据进行验证。
